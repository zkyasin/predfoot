# Tutorials

Numbered, self-contained notebooks, in the order a newcomer should read them:

1. `01_Getting_Started_with_predfoot` — load a clip, calibrate one frame, draw the reprojected pitch.
2. `02_From_Pixels_to_Pitch` — positions, Jacobians and why far players are less certain.
3. `03_Uncertainty_and_Coverage` — ellipses, conformal calibration, reading a coverage table.
4. `04_Physical_KPIs_Error_Budget` — what position noise does to distance, HSR and sprints.

Drafts live in `notebooks/exploratory/`, which git ignores.
